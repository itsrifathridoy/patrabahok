File format

One user per row. Columns, in order:

email
Full address, or a username to use the default domain. Required.
name
Full name. Optional.
password
Optional, at least 8 characters. Left empty, a strong one is generated.
quota
Optional, e.g. 500M or 2G.

A header row is detected and skipped. Existing addresses are reported and left unchanged. Each row is created independently, so one bad row doesn't stop the rest.
